# Code of Conduct

This project adopts the **Contributor Covenant 2.1** as its code of conduct.

The full text is at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good intent, and report problems by emailing `conduct@mcpverify.dev`. Maintainers will respond within 48 hours and act on credible reports of harassment or abusive behavior.

By contributing to this project you agree to abide by the Contributor Covenant 2.1.
